# How to Download and Use Streisand

Getting started only takes a few minutes.

### Step 1. Prepare a US Apple ID

You will need a US Apple ID before downloading Streisand from the App Store.

Read this guide:

https://npvtunnel.dev/zh/docs/npvtunnel教程/苹果手机如何下载npvtunnel/

After logging into the App Store, search for **Streisand** and install it.

---

### Step 2. Open Streisand

Launch the application and tap the **"+"** button in the upper-right corner.

![streisand-1001.jpg](https://streisand.onl/img/streisand-10013.jpg)

---

### Step 3. Import Your Subscription

Choose one of the following options:

- Import from Clipboard
- Manual Configuration → Subscription

Paste your subscription URL and save it.

---

### Step 4. Connect

Select any available node and tap **Connect**.

![streisand-10018.jpg](https://streisand.onl/img/streisand-10018.jpg)

The first time you connect, iOS will ask permission to create a VPN configuration.

Simply tap **Allow** and enter your device passcode.
